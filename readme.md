# Data Visualization Libraries Practice

Hands-on practice with Python data visualization libraries, using the NumPy and pandas workflow I already learned.

## Libraries

- **matplotlib**: low-level plotting with full control over figures, axes, and styling (line, bar, scatter, histogram).
- **seaborn**: statistical plots built on matplotlib (distributions, categorical comparisons, heatmaps, pair plots).

## Setup

```bash
pip install numpy pandas matplotlib seaborn
```
